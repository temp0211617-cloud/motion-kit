# Accessibility Standard

Every relevant component must address:

- semantic HTML
- keyboard navigation
- visible focus
- touch interaction
- reduced motion
- labels/names
- disabled states
- logical focus order
- adequate target size
- contrast

Dialogs/drawers/menus require correct focus management and Escape behavior.
Carousels require labeled controls, keyboard support, controlled autoplay, and reduced-motion behavior.
Hover-only behavior must have a touch/keyboard equivalent or be decorative only.
